# Seeker 실기기 확인 결과 - 0.4.1

2026-09-28 · Solana Seeker · Android 15

## 완료한 내용

- Seeker에 0.4.0 신규 설치 후 0.4.1로 데이터 삭제 없이 업데이트했다.
- 실제 지갑 연결과 Solana 공개 RPC를 통한 실제 내역 조회가 동작했다.
- 첫 조회 실패는 휴대폰 인터넷 미연결 상태였다. 사용자가 Wi-Fi를 연결한 뒤 실제 내역을 가져왔다.
- 작은 Qwen3-0.6B 모델의 출력 형식 오류와 질문 선택 품질 문제를 발견했다. 공개 Qwen3-1.7B INT4 모델로 변경하고 분류 지침과 응답 해석을 수정했다.
- AI 실행 검사에서는 개인 기록 대신 별도 검증 앱과 예시 문장을 사용했다. 저장된 지갑 기록을 읽거나 거래를 실행하지 않았다.
- 모델을 받은 후 Wi-Fi를 끊고 기본 인터넷 경로가 없는 상태를 확인했다. 영어·한국어 개발 예시 8개가 모두 의도한 질문 종류를 선택했다.
- 호출당 15.1~16.8초, 중앙값 15.7초였다. 모델 파일 무결성 검사와 엔진 초기화를 포함한 호출 시간이다.
- Wi-Fi를 다시 켜고 이전 네트워크 재접속까지 확인했다. 별도 검증 앱과 그 모델·캐시를 삭제하고 실제 앱을 유지했다.
- 정적 분석 문제 없음, 기존 Flutter 검사 92개 통과, 0.4.1 릴리스 APK 빌드 성공.

## 결과의 범위

8개 예시는 지침을 다듬는 개발 과정에서도 사용했다. 독립적인 정확도 평가나 모든 기록에서의 품질 보장은 아니다. 실제 앱의 최적화된 배포 환경 전체를 이 별도 검증으로 대체하지 않는다. 질문이 맞지 않으면 모델 없이 직접 다섯 질문 중 하나를 고를 수 있고, 수동 선택을 AI 결과로 표시하지 않는다.

현재 확인한 실제 지갑 내역은 지원 스왑으로 분류되지 않았다. **실제 지원 거래 → 이유 저장 → 재실행 → 회고·기준 저장의 전체 실기기 경로는 아직 확인하지 못했다.** 이를 위해 실제 거래를 새로 만들지는 않았다.

AI 첫 사용 시 실제 앱 안에서 약 978 MB 모델을 한 번 다운로드해야 한다. 검증 앱의 다운로드를 실제 앱의 준비 완료로 간주하지 않는다. API 계정과 유료 AI 서버는 필요하지 않다. 모델 초기화용 추가 캐시도 생길 수 있으며 모델 삭제 시 함께 정리하도록 했다.
