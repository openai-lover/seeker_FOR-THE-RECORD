## What happened in the normal app

1. Open the room and use existing read-only MWA/Seed Vault account authorization.
2. Refresh actual direct Solana RPC activity. Select an activity that had no prior journal.
3. Save a new explicitly agent-authored DEMO reason, with No date.
4. Immediately revisit manually, write a DEMO reflection, run one local question request, choose a candidate as the operator, and save a DEMO lesson.
5. Complete Android's native file picker export, then privately validate the nonempty JSON before force-stop.
6. Force-stop/reopen the production app, open the same saved record, complete a second export and privately compare the full journal payload.

The activity is **successful Other**, not a supported live swap or proof of owner v1 activity. No message/transaction signing, trade, asset movement or payment occurred. Guarded v1 compatibility is verified in the separate [same-sample public report](PUBLIC_RPC_V1_COMPATIBILITY_0512.md); this owner-device flow is not substituted for that evidence.
